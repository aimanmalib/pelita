# ADR 0006: Site v0 (static page over the indexer snapshot)

Status: accepted, 17 Nov 2026

## Context

PRD §4.7 asks for one page, plain HTML + CSS + JS with no build step, six sections in a fixed order, data from
`/data/snapshot.json` (polled every 30 s) and a fuel gauge that reads the Lasna RPC from the browser. §4.1 locks the look:
warm dark, one amber accent, a lamp glyph per contract (amber lit, grey dark), self-hosted fonts, no third-party script,
no `backdrop-filter`/animated blur. The contracts are not deployed yet, so v0 is built and tested on sample data.

## Decision

- `web/index.html` + `web/css/site.css` + small ES modules in `web/js/` (`i18n`, `format`, `lamp`, `fleet`, `gauge`, `app`).
  No framework, no bundler.
- All text lives in `web/lang/en.json` and `web/lang/ms.json` (same keys, checked by `tests/test_web.py`). Default EN,
  choice kept in `localStorage` inside `try/catch`.
- Settings live in `web/site.json` (poll interval, stale threshold, table size, links, gauge fill amount, median fee once
  measured). Chain RPCs, billers, explorers and selectors are NOT copied: the page reads `config/chains.json`, which the
  deploy (P1g) serves at `/config/chains.json`. One source of truth.
- The lamp glyph is inlined by `web/js/lamp.js` instead of `<use href="#symbol">`: page CSS does not reach into a `<use>`
  shadow tree, so a `<use>` glyph cannot change colour between lit and dark or animate its flame (seen in the first
  screenshots: the header glyph rendered black).
- The flame flickers with `transform` + `opacity` only; `prefers-reduced-motion` turns it off. The header is a solid
  colour (no glass).
- Fonts: Newsreader (headings, numbers), Public Sans (text), IBM Plex Mono (addresses, commands); all OFL 1.1, served
  from `web/fonts/`.
- The page reads two snapshot fields the indexer does not write yet: `events[].ts` (for "last relight … ago") and
  `demo` (`chain`, `beacon`, `last_beat_ts`, `cooldown_seconds`, for "Try it yourself"). Without them the page shows
  "none yet" and "appears once Beacon is deployed". The indexer writes both since 17 Nov (ADR 0004).
- The dark list follows PRD §4.7.5: tiles (outages, still dark, median time dark, median debt) and a table of
  address, dark for, debt. The census reads `biller.debt(address)` for every still-dark address in JSON-RPC batches
  at the last block it read (so the same range gives the same numbers) and writes `dark[].debt_wei` plus
  `debt_wei` quantiles, as decimal strings because the browser's JSON loses precision above 2^53 wei. If the node
  cannot answer (pruned state), the census publishes without debt and the page shows a dash.
- The gauge keeps its last reading and message in the page state; switching language draws them again.
- `scripts/web-smoke.py` serves the site the way the deploy will, stubs the Lasna RPC, and checks Chromium (1366 and
  390 px) and WebKit iPhone 13 (390 and 320 px): no console errors or failed requests, no horizontal overflow, language
  toggle swaps every text (the gauge reading too, read before the switch), gauge validates and reads, dark table shows
  debt. Host tool (Playwright), not part of the offline gate.

## Way back

If the debt reads slow the indexer, drop the `read_debts` argument in `ops/indexer.py`: the census and page work
without the debt fields.

The page is static files; any section can be removed from `index.html` without touching the others. If module scripts
cause trouble on an old browser, the modules concatenate into one classic script with no other change.
