- 2026-11-23 (demo loop lit) — The network authorised a delivery sender again, but the next beat's delivery still reverted: the proxy wants about 130000 gas left and the operator sends each delivery with exactly the gas the reactive contract asked for, so the Flicker's 100000 could never get through (`InsufficientGas`, read with `eth_call` on the parent block; ADR 0008). The callback gas is now 300000, the deployer refuses anything under a measured per-chain floor and replaces a Flicker whose fixed gas differs, releasing the old one from the Keeper. With the new pair, one public `poke()` lit the Lantern one second later (`docs/evidence/E-004-demo-loop.json`). The evidence reader also had to start one second earlier and pick this Flicker's reaction, since the retired one reacts to the same beat.
